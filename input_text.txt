Хеш-таблица это структура данных для хранения пар ключ-значение.
Хеш-функция преобразует ключ в индекс массива.
Коллизии возникают когда разные ключи имеют одинаковый хеш.
Существует два основных метода разрешения коллизий.
Первый метод это открытая адресация с линейным пробированием.
Второй метод это использование связных списков или цепочек.
Hash table is a data structure for storing key-value pairs.
Hash function converts a key into an array index.
Collisions occur when different keys have the same hash.
